# Playtest records

Copy [_template.md](_template.md) to `<YYYY-MM-DD>_<gate>_<scenario>.md`. Keep raw telemetry in `Saved/Playtest/` (ignored by Git); record its file name and summarize the evidence here. A dry run checks the recording process; gate approval still requires the owner review and every checklist item in [master plan section 3](../main_implement_plan.md#3-delivery-phases-and-gates).

Use Pass / Fail / Not tested / Out of phase explicitly. Give an evidence reference for each result and a KEEP / CHANGE / DELETE decision for each hypothesis. Record owner questions and unresolved findings with task IDs; do not pass a gate while required evidence is missing.
