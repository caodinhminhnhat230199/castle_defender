# Game Development Workflow Skill

A modular workflow skill for end-to-end game development.

## Scope

This skill manages **HOW TO DEVELOP**:

- requirements
- gameplay specification
- production planning
- technical planning
- task breakdown
- prototyping
- vertical slices
- implementation flow
- playtesting
- profiling
- QA
- release
- scope control
- quality gates

For **HOW TO BUILD IT IN UE5**, use the sibling `ue5-project-architecture` skill.

## Progressive Disclosure

`SKILL.md` is a router. Read only the references needed for the current task.

## Typical Pairing

```text
game-development-workflow
        ↓
process / gates / deliverables
        ↓
ue5-project-architecture
        ↓
UE5-specific architecture decisions
```
