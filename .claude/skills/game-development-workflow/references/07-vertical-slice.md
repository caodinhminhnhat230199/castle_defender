# Vertical Slice

## Load When

Use before scaling content or committing to full production.

## Purpose

Build one small, representative, end-to-end playable experience.

## A Vertical Slice Should Prove

- core gameplay loop
- input/control
- player feedback
- enemy/encounter behavior
- objective flow
- UI readability
- art direction at representative quality
- audio/VFX integration
- performance direction
- failure/retry flow
- build/package viability

Not every project needs every item.

## Slice Rule

Do not scale:

- enemy count
- level count
- item count
- class count
- tower count
- quest count
- world size

until the representative loop works.

## Gate Questions

1. Is it fun enough to continue?
2. Is it technically feasible?
3. Does the content pipeline work?
4. Can the team produce more content using the same approach?
5. Does it meet target hardware constraints?
6. Are the major unknowns reduced?

## Output

Record:

- what was proven
- what failed
- what changed
- what remains uncertain
- whether scale-up is approved
